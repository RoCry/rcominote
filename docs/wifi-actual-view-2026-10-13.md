## 状态 `96` 不等于 Wi-Fi 状态机

`10015af2` 先要求 UI global 非零，否则返回 −1；随后将原始 `r2`（保存于 `r6`）作为整数打印 `wifi_ota_state == %d`。仅当值为 1 时：

1. `10015b1c` 将 view ID `33` 传给 `1008ef84`。该函数遍历实际视图栈条目，比较 ID 并可能缩短栈；它不是无线初始化器。
2. 若返回值非零，`10015b28..10015b30` 调用 `100b8634(33, 0)`。此 wrapper 构建 16 B 视图栈参数（ID 在 +0c、presenter 在 +08），进入 `1008ece8` 的栈更新路径；形态与参考 `view_stack_jump_view()` 一致。
3. 注册记录 `[10000524,1000053c)` 将 view `33` 关联到 app 名 `record_launcher`。故该条件的可确认效果是回到/切换至录音主界面，而非“连接 Wi-Fi 成功”或“OTA 校验成功”。

其他状态值只打印后返回。本范围没有进度百分比处理、SSID/IP、文件块读取或网络启动调用的正证据。所有第三方库 helper 未递归展开；结论是这条已审分支没有建立传输链，而非声称任意外部调用均已证明无副作用。
